# block-engine-mvp

Ambiente de programação visual (Blockly-inspired) onde jogadores usam blocos de código
para controlar um personagem em labirintos. Inclui sistema de RPG com atributos, baús,
e mecânica de dano com armadura.

Consulte [CONTEXT.md](./CONTEXT.md) para histórico completo das sessões e
[AGENTS.md](./AGENTS.md) para documentação técnica.
